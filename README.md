# Student Performance MLOPS

## Project Overview
This project focuses on analyzing and predicting student academic performance using Machine Learning and MLOps practices.

## Features
- Student performance prediction
- Machine learning model training
- Backend application using Python
- Model testing and evaluation

## Technologies Used
- Python
- Machine Learning
- FastAPI
- Git and GitHub

## Project Structure
- `app/` – Application and API code
- `src/` – Model training and source code
- `tests/` – Project tests
- `requirements.txt` – Python dependencies
